## System Architecture

### Real-Time Tracking Architecture

```text
Driver Application
        |
        v
  Socket.IO Gateway
        |
        v
    Redis Layer
        |
        v
  Backend Processing
        |
   +----+-----+
   |          |
   v          v
Database   Live Updates
              |
              v
     Passenger Application
```

**Design considerations:**

- Separate location ingestion from client broadcasting.
- Reduce unnecessary database writes.
- Support multiple connected clients.
- Improve reliability through asynchronous processing.
- Keep services independently maintainable.

### Cloud Deployment Architecture

```text
             Developer
                 |
                 v
           GitHub Push
                 |
                 v
          GitHub Actions
             CI/CD
                 |
                 v
         AWS IAM / OIDC
                 |
                 v
             AWS EC2
                 |
                 v
          Nginx Proxy
                 |
                 v
        Docker Containers
                 |
        +--------+---------+
        |        |         |
        v        v         v
     Node.js  PostgreSQL  MinIO
       API                 Storage
        |
        v
   Application Logs
        |
        v
   Monitoring Stack
   Grafana / Loki
```

**Deployment principles:**

- Automate builds and deployments.
- Use short-lived deployment credentials through OIDC.
- Isolate application services using Docker networks.
- Keep sensitive configuration outside source control.
- Centralize application logging.
- Design infrastructure for maintainability.
