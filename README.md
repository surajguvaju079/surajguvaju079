## Smart Bus Architecture

```text
Driver App
     │
     ▼
Socket.IO Gateway
     │
     ▼
Redis Streams
     │
     ▼
Consumer Group Workers
     │
 ┌───┴────┐
 ▼        ▼
PostgreSQL   Live Broadcast Engine
                 │
                 ▼
          Passenger Applications
```

**Why this shape:** it absorbs high-frequency GPS writes without hammering the database, decouples ingestion from broadcast so either side can scale independently, and keeps message processing fault-tolerant via consumer groups.
